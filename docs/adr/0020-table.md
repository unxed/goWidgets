# ADR-0020. Таблица с колонками (Table)

* Статус: принято
* Дата: 2026-10-22
* Затрагивает: `core.WidgetKind`, `core.Caps`, публичный API окна

## Контекст

Showcase `zipgui` (ADR-0019) показывает записи архива в нескольких колонках и
должен сортировать их по нажатию заголовка. `ListBox` из ADR-0012 содержит
только текстовые строки и не представляет заголовки или табличные ячейки.
Немедленное добавление нативного контрола во все драйверы не помещается в
атомарный шаг 4a; дальнейшие части 4b–4e добавят реализации платформ.

## Решение

1. Core получает `KindTable`, `TableColumn` (`Title`, `Align`) и
   `EventHeaderClicked`; выбор и активация строк используют существующие
   события `EventSelected` и `EventItemActivated` с индексом строки.
2. Окно может реализовать необязательный интерфейс `TableWindow` для
   установки колонок, строк и индикатора сортировки. Только драйвер,
   реализующий это расширение, объявляет `Caps.GridView=true`.
3. Публичный API `Window.AddTable` предоставляет `SetRows`, `Rows`, `Select`,
   `SelectedIndex`, `SetSortIndicator` и события `Selected`, `Activated`,
   `HeaderClicked`. Сортирует данные приложение; драйвер только отображает
   направление сортировки. `SetSortIndicator(-1, ...)` убирает стрелку.
4. Если окно не реализует `TableWindow`, API создаёт `ListBox`: ячейки
   выравниваются пробелами по ширине каждой колонки и соединяются строкой
   `  │  `. В этом режиме `Fallback()` возвращает true, заголовочных событий
   нет, а индикатор сортировки игнорируется.
5. Headless реализует `TableWindow`, хранит столбцы, строки и индикатор и
   предоставляет синтетические события выбора/активации строки и нажатия
   заголовка для регрессионных тестов.

## Последствия

* API таблицы можно использовать до появления нативных реализаций, не
  блокируя приложение на конкретном драйвере.
* Запасной список сохраняет отображение ячеек и выбора, но не сортировку
  заголовком и не визуальные стрелки.
* Каждый следующий платформенный драйвер получает `Caps.GridView` только
  вместе с полной реализацией `TableWindow`.

## Альтернативы

* Расширить `ListBox` заголовками и набором ячеек — отвергнуто: это меняет
  контракт уже существующего простого списка.
* Сделать `GridView` обязательным для всех драйверов сразу — отвергнуто:
  этапность платформ уже задана планом zipgui, а `ListBox` позволяет
  пользоваться таблицей до завершения паритета.
