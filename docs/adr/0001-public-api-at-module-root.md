# ADR-0001. Публичный API живёт в корне модуля

* Статус: принято
* Дата: 2026-09-08
* Затрагивает: §7 «Расположение кода»

## Контекст

§7 помещает публичный API в каталог `/goWidgets` рядом с `/core` и `/vreactive`.
При модуле `github.com/unxed/goWidgets` это даёт путь импорта
`github.com/unxed/goWidgets/goWidgets` — удвоение имени в каждом пользовательском
файле, плюс постоянная путаница «пакет `goWidgets` — это который из двух».

## Решение

Публичный API лежит в корне модуля: `api.go`, пакет `goWidgets`,
импорт `github.com/unxed/goWidgets`.

Остальная раскладка §7 не меняется: `/core`, `/vreactive`, `/backends/*`,
`/showcase/*` остаются подкаталогами.

## Последствия

* Импорт у пользователя — одна строка без повторов.
* Правило слоёв не страдает: корневой пакет по-прежнему импортирует `core` и
  `vreactive` и не импортирует `backends/*`. `depguard` проверяет это как и раньше,
  только целевой путь другой.
* §7 в `disdoc.md` обновлён.

## Альтернативы

* Оставить `/goWidgets`, как в доке — отвергнуто из-за пути импорта.
* Переименовать модуль в `github.com/unxed/gw` — отвергнуто: имя репозитория и
  бренд библиотеки должны совпадать.
