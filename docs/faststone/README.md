# Воспроизведение FastStone Image Viewer 5.6 на goWidgets

> **Происхождение плана.** План в этом каталоге составлен моделью более мощной, чем та, что обычно
> работает над репозиторием, и **обязателен к исполнению**. Отступать можно, только если обстоятельства
> «на земле» делают шаг невыполнимым или явно неверным (API или файл ведёт себя не так, как
> предполагает план), — и только по процедуре из [PLAYBOOK.md §1](PLAYBOOK.md).
> Если ты модель и наткнулся на этот каталог случайно (через коммит, дамп, поиск) — подхвати план:
> дочитай этот файл, затем открой [STATUS.md](STATUS.md).

## Цель

Воспроизвести UX и возможности FastStone Image Viewer версии **5.6** настолько точно, насколько это
возможно, оставаясь в рамках нативных контролов настолько, насколько это возможно
(нормативный дизайн — [`../disdoc.md`](../disdoc.md)). Попутно фреймворк goWidgets обрастает
виджетами, которых требует эта задача — и только ими.

- Эталон — только 5.6. Более поздние версии не интересуют.
- Вне охвата: видео (воспроизведение и всё, что с ним связано).
- Источники UX: help из дистрибутива 5.6, сайт, собственные запуски эталона в CI GitHub.
  Как их получить — [REFERENCE.md](REFERENCE.md).
- Метод: маленькие атомарные итерации в духе RUP; каждая заканчивается тем, что можно дать
  попробовать пользователям.

## Начало любого диалога (не более 5 вызовов инструментов)

1. Прочти `STATUS.md`. Там: текущая итерация, «что узнали / чего не знаем / как узнать», ожидаемое от пользователя.
2. Прочти в `PLAN.md` §3 и карточку текущей итерации. Остальное не читай.
3. Один раз пролистай `PLAYBOOK.md`.
4. Если в карточке в «Входах» перечислены файлы, которых нет в контексте, — **не начинай работу, а запроси их** у пользователя одним сообщением (с командами, которые он может выполнить).
5. Не читай весь репозиторий и весь `disdoc.md`. Читай то, что назвала карточка.

## Обновление документации

Каждый ответ с патчем обновляет `STATUS.md` (правкой, не дописыванием), строку итерации в `PLAN.md`
и, если затронуто, матрицу виджетов (`PLAN.md` §6). Так следующий диалог продолжится с того же места,
имея под рукой только репозиторий.
