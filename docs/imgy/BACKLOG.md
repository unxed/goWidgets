## 3. Известные риски

- **R1** Qt: Canvas требует показать пиксельный буфер и получить события мыши/колеса без C API Qt. Снимается спайком B5 до Построения.
- **R2** Производительность масштабирования больших изображений в чистом Go. Смягчение: D2 (быстро при движении, качественно в покое, фоновая горутина, отмена устаревшего).
- **R3** Текст на Canvas (подписи миниатюр, OSD): шрифты и кириллица. Решается спайком в C3 (D5).
- **R4** HiDPI: буфер Canvas в физических пикселях, координаты в DIP (D8). Проверять на масштабе 1 и 2 в headless-тестах.
- **R5** Wine ≠ Windows: «зелёный» win32test не гарантирует реальную работу (см. Q6).
- **R6** Cocoa не проверяется на Linux-CI (см. Q5).
- **R7** Поведение эталона, не описанное в help: без скриншотов/подтверждения пользователя фичу не реализуем «по догадке» (REFERENCE §7).
