# Инвентарь возможностей

Фиксируем разделы по одному за ответ. Формулировки — краткий пересказ своими словами; файлы эталона и текст справки сюда не копируем. Видео — вне охвата по решению владельца. Всё остальное остаётся в охвате, пока пользователь явно не перенесёт или не исключит возможность.
